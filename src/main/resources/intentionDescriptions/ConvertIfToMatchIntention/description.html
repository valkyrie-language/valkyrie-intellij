Converts if statements to match expressions for better pattern matching.

This intention converts:

  • Regular if statements to match expressions with true/false patterns
  • If-let statements to match expressions with pattern matching

Before:


if condition {
    // then block
} else {
    // else block
}

After:


match condition {
    true => {
        // then block
    },
    false => {
        // else block
    }
}
